# موقع ورشة أبانوب أشرف

موقع ثابت باللغة العربية لعرض أعمال وتصميمات النجارة والأثاث والديكور، مع دعم اتجاه الكتابة من اليمين إلى اليسار.

- **الموقع المنشور:** https://abanoubfurniture.vercel.app/
- **نوع المشروع:** HTML / CSS / JavaScript — لا يحتاج إلى عملية build أو تثبيت حزم لتجربته محليًا.

## المميزات

- تصميم متجاوب للهواتف وأجهزة الكمبيوتر.
- معرض للأثاث مع تصفية حسب الفئة، وتحميل المزيد، وعرض الصور المكبّر.
- أقسام لأعمال الورشة والفيديوهات وبيانات التواصل والعنوان.
- روابط اتصال وواتساب وبيانات منظمة لمحركات البحث.
- إعدادات `robots.txt` و`sitemap.xml`.

## الملفات

- `index.html` — صفحة الموقع الأساسية، والتنسيقات والسكريبتات المضمنة.
- `robots.txt` — تعليمات زحف محركات البحث ورابط خريطة الموقع.
- `sitemap.xml` — خريطة الموقع لمحركات البحث.
- `_headers` — ترويسات أمنية لمنصات الاستضافة التي تدعم صيغة ملف `_headers`؛ ليست كل المنصات تتعرف على هذا الملف.

## المعاينة محليًا

افتح `index.html` في متصفح حديث. صور المعرض مستضافة خارجيًا على Cloudinary، لذلك يلزم اتصال بالإنترنت لعرضها.

## النشر

يمكن نشر الملفات كموقع ثابت على منصة استضافة تدعم HTML. قبل النشر على نطاق مختلف، حدّث روابط النطاق في بيانات `canonical` وOpen Graph وبيانات النشاط التجاري داخل `index.html`، ورابط خريطة الموقع في `robots.txt` وعنوان الموقع في `sitemap.xml`.

> ملاحظة: ملف `_headers` يُستخدم فقط على منصات تدعم هذه الصيغة. راجع إعدادات منصة الاستضافة للتأكد من تطبيق الترويسات الأمنية بالفعل.
